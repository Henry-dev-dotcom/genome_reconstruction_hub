# Deployment Guide
## Group 2 Genome Reconstruction Hub

This website is a static single-page project. You can share it locally or publish it online.

## Option 1: Open Locally
1. Extract the ZIP folder.
2. Open the folder.
3. Double-click `index.html`.
4. The website opens in your browser.

## Option 2: Share with Group Members
1. Send the full project folder or ZIP file to your group.
2. Tell them to extract it.
3. Tell them to open `index.html`.

## Option 3: Publish with GitHub Pages
1. Create a GitHub account.
2. Create a new repository.
3. Upload all project files:
   - index.html
   - style.css
   - script.js
   - favicon.svg
   - study-notes.md
   - presentation-guide.md
   - README.md
4. Go to repository Settings.
5. Click Pages.
6. Choose the main branch as the source.
7. Save and wait for GitHub to generate a website link.

## Option 4: Publish with Netlify
1. Go to Netlify.
2. Use Netlify Drop.
3. Drag the project folder into Netlify.
4. Netlify will create a public link.

## Option 5: Publish with Vercel
1. Go to Vercel.
2. Import the project from GitHub.
3. Deploy as a static site.

## Important Note
Keep all files in the same folder so the CSS, JavaScript, favicon, and downloadable notes load correctly.
